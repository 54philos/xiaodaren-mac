# 点读伙伴 0.5.0

非官方小达人 macOS 客户端。SwiftUI、Foundation、CryptoKit，无运行时第三方依赖。最低 macOS 14，交付二进制为 arm64。

## 构建与核心测试

```sh
bash build.sh
bash build.sh test
```

`PEN_BUILD_DIR` 可指定中间文件目录，默认 `.build`。构建脚本只在本次编译中用 VFS overlay 屏蔽 CLT 的重复 SwiftBridging 定义，不修改系统文件。

72 项自包含检查通过，覆盖安装及直接移除。UNB 测试目录起初没有 169.das；仅用源 DAB 和 fixture PRODUCT.INI 安装成功，验证独立绑定、不改源文件、保留 payload、占用保护和范围边界。可选的真实 Wow English 只读审计仍可通过 build.sh test 的两个附加路径参数运行；不再硬编码书目总数。

## UNB 独立绑定依据

官方来源：https://api.maiya.com/download.php?file=maiya.apk

样本 Android 1.2.7，SHA-256：`e6272db1dd0c0ace0d0b1c7eec2ad4e01c87852443162415d351ba8c14905238`。

通过只读字节码检查定位 `q0.a.b` 的 UNB 智能分支、`q0.a.a` 的 UNB 普通分支及共同设备标识派生逻辑。开发资料和官方安装包仅保留在工作目录，不随源码或应用分发。

UNB 规则：

- 标识字符串：`0x3f..<0x5f`，32 字符十六进制。
- 设备 selector：`0x95`，随机 1..254。
- 设备 token：`0x96..<0x9a`，与已实现的 PRODUCT.INI 派生值使用同样的 XOR 公式。
- 智能 UNB 只写上述 5 字节；内置书码、索引、音频保持原样。
- 普通 UNB 额外写入 `u16(content) XOR u16(header[0xa1..<0xa3])` 至 `0x8d..<0x8f`，明确拒绝超过 65535 的内容码。
- UNB 不使用 common-DAB 的 0x150 槽号换算，不提供 direct/封面码重写。

默认类型启发式：UNB 内置书码 `u16(0x5f)` 为 0 时建议 DAR，否则建议 DAS。它匹配当前 16 个只读对照样本，但最终类型允许用户按商家说明核对选择。不要把文件槽号变化视作修改内置 OID。

生产安装路径不接受原包模板、不读取旧包头生成绑定信息。0.2 的模板重装实现已移除。扫描书目只用于列表及占用保护。

## 验证工具

`Tests/UNBReadOnlyAudit.swift` 与 PenCore.swift 一起编译：参数为源 DAB、点读笔根目录、预先独立记录的正常整包 SHA-256。它只从 PRODUCT.INI 派生绑定，以固定 selector 0x52 对照牛津树已知完整哈希，不读取旧点读包或备份，不写设备。

`Tests/USBSmoke.swift` 与 PenCore.swift 一起编译：显式硬件写入测试。先选一个尚不存在的目标槽，使用标准生产安装方法安装源 DAB，回读核对独立 token 与完整不可变区域，清理自己生成的文件，核对前后原书目一致。UNB 按默认类型测试；普通内容贴测试入口的起始码固定为 1。硬件测试有写入，不能当只读审计运行。

2026-10-20 用户确认：0.3.1 从原始牛津树 DAB 独立安装后，拔线重新开机，实体书点读全部正常。0.3.2 的改动仅针对安装 I/O 与进度显示；单次完整回读算法已通过本地检查，真实硬件速度尚未重新计时。

## 安装和移除

4 MB 分块复制；先校验绑定前后头部的不可变字段；复制时计算预期 SHA-256，写入并同步完成后对临时文件完整回读一次，比较整包 SHA-256，通过后再提交。头部和音频区分别注入损坏验证失败清理。避免原先 unchanged 全量比较后又 digest 的重复设备读取，也省去一次源包重读。回读进度覆盖 75% 至 99%，复制结束到同步完成期间明确显示正在写入设备。校验 PRODUCT.INI 未改变，拒绝符号链接设备目录，拒绝覆盖被占用的槽。文件创建使用独占 NSData 写入，兼容此次 FSKit FAT 设备。

0.3.1 按用户需求移除两个备份入口及备份逻辑，改为直接移除所选。确认框显示书名、文件编号和不可撤销提示，默认按钮为取消。移除时重新校验设备、内容目录、编号/扩展名、普通文件及大小，不复制或完整读取大包。搜索隐藏的选中项不能移除。测试覆盖越界路径、符号链接、编号不符、过期选择、设备变化、只移除目标文件、保留源包及移除后独立重装。

## 第三方许可

common-DAB 的 DAS/DAR 算法参考 MIT 许可项目 kings0527/talking-pen-toolkit。详见 THIRD_PARTY_LICENSE.txt。核心来源 blob：dab_binding.py `f4a6b9afbeb5b90cdfbd099ecec0bc47fdef6735`、dab_importer.py `8a3812e36c5d0d38409a5a9c0bb13e88fb448499`。UNB 使用同一设备派生公式，分支字段由官方客户端静态核对及当前设备对照确认，未分发官方反汇编代码。

0.3 同时将设备发现、书目读取、剩余空间读取移到后台；仅列书目时不再定位文件尾部。耗时 I/O 不在 SwiftUI body 中执行。

## 0.4 列表管理

原生 Table 使用 Set<Book.ID> 多选与 KeyPathComparator 排序，默认 slot 升序，大小列比较 UInt64 字节数。删除入口右对齐，选中数量只统计当前可见条目，搜索变化时移除隐藏选择。确认框展示完整文件清单，超长时滚动。

批量删除先检查所有文件，再逐个复核与移除；出现失败立即停止，反馈具体完成数与文件名。63 项检查含失败前置检查保留全部内容，以及处理中变更导致部分失败的报告与剩余文件保留。

自动发现每 4 秒检查设备和书目元数据（路径、大小、修改时间）；元数据改变时后台读取书名并刷新，保持仍可见且存在的选择，不重复读取未变化书目。手动选盘及刷新移至 File 菜单。

## 0.4.1 安装完成界面

侧栏移除磁盘名与型号/编号/日期文本；保留内部设备标识校验。run 增加仅成功时调用的主线程回调，install 在回调中重置包、参数、搜索、选择和默认排序，再异步刷新书目。失败不重置，其他操作不触发安装表单重置。成功状态提示保留。

## 0.4.2 快速安装

App 默认 fullVerification=false（UserDefaults 持久化，File 菜单切换）。快速路径同步写入后检查大小与 383 字节绑定包头，不读取整包音频、不计算流式 SHA-256。完整模式仍流式计算哈希并一次回读。核心 install 参数默认 true 以保留现有审计工具的完整校验行为，App 显式传入用户选择。快速模式仅显示安装完成，不能宣称整包校验通过。72 项本地检查含快速标准/UNB 安装、头部/长度损坏拒绝与临时文件清理，原有完整模式音频损坏注入检查保留。

## 0.4.3 操作精简

侧栏安全推出按钮置于版本号上方，移除 UNB 功能标语。install 移除 NSAlert 二次确认，保留参数校验并直接调用 run；busy 前置检查防止连续重复点击。移除内容的确认框保留。
