# 使用说明

## 安装应用

从 Releases 下载 `DianduPartner-0.5.0-macOS-arm64.zip`，解压后将「点读伙伴.app」拖入「应用程序」。适用于 M 系列 Mac、macOS 14+。当前未做 Apple 公证，首次打开提示请参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 连接点读笔

将点读笔关机，使用可传输数据的数据线连接。未自动识别时，从「文件 / File」菜单选择磁盘根目录（包含 SYS 和 USER 文件夹），或按 ⌘R 刷新。

## 安装点读包

选择自己的 DAB，按照资源说明核对编号和类型。普通内容包需要起始内容码；封面直接进入类型需要封面码。UNB 沿用资源提供方的原包编号，内置书码保留。点击安装即开始，成功后自动收起参数并恢复完整列表。

已有编号不会被覆盖。要重装同一编号，先在已装列表中选中对应文件并移除。

## 快速安装与完整校验

默认快速安装，复制完成后等待写入结束，并核对文件大小和包头，不会完整读取音频区。

在「文件 / File」菜单勾选「安装后完整回读校验（较慢）」可检查整个写入文件。选择会保存。完整校验失败会停止、清理临时文件并提示重装，不会自动重试。

## 管理已装内容

点击表头排序，默认按贴号升序；点击大小可切换升序和降序。⌘ 点选多个不相邻条目、⇧ 连选连续条目，表格聚焦时 ⌘A 选择当前结果。

右下角「移除所选」会列出确认清单，一次确认后直接移除。搜索隐藏的选择不会参与移除。文件删除后不能撤销，不会创建备份。批量处理遇到错误会停止并报告已经移除的数量及文件。

## 结束使用

等待安装或移除完成，点击左下角「安全推出」，成功后再拔线。安装后请开机测试实际纸质书。

## 支持范围

已验证一支小达人 908，其他型号需实际测试。当前支持 deb 智能包、标准 2/3 普通内容包和 UNB 包；没有在线资源下载、MP3 制包或固件升级。
